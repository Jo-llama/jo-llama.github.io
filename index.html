Selected Projects

Clause Harness

Python · Claude · CUAD · Structured Output · Eval Loop

LLM-based contract clause review harness. Extracts eight CUAD clause types as schema-validated structured output, runs a second reworded pass to catch confidently wrong answers, and verifies every cited span against the source text. Clean results auto-pass; anything unverifiable escalates to a lawyer with the reason attached.
