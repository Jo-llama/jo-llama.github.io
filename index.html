My Approach

01

Process Analysis — Status Quo

  • Map how the process actually runs today: people, handoffs, tools, exceptions.
  • Identify where time, accuracy, or compliance breaks down.
  • Define what's automatable and what still needs a human.
02

System Architecture — AI & Automation

  • Design the agentic/automation architecture: tools, guardrails, evaluation loops.
  • Decide what an LLM should do versus what deterministic code must own.
  • Prototype and validate against real cases before committing to a build.
03

System Integration — Technical Partner

  • Hands-on rollout as the technical point of contact on the client side.
  • Coordinate with platform and service providers (APIs, SaaS, cloud) to wire the system in.
  • Stay embedded through go-live: troubleshooting, handover, documentation.

Selected Projects

Clause Harness

Python · Claude · CUAD · Structured Output · Eval Loop

LLM-based contract clause review harness. Extracts eight CUAD clause types as schema-validated structured output, runs a second reworded pass to catch confidently wrong answers, and verifies every cited span against the source text. Clean results auto-pass; anything unverifiable escalates to a lawyer with the reason attached.
